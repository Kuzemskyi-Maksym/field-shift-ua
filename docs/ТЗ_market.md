# ТЗ: модуль «Куди продати і як довезти» (полегшена версія) — ніч 14→15.11

Мета: у картці поля і в #plan показати для рекомендованих культур:
(1) куди Україна реально продає цю культуру (країни, обсяг, ціна в дол./т);
(2) до якого порту найближче поле і скільки км;
(3) скільки дає порт проти елеватора — лише там, де обидві ціни з одного джерела й дати;
(4) ризики маршрутів текстом, без цифр.
Беззбитковість доставки рахуємо ЛИШЕ якщо знайдено тариф з джерелом.

## Жорсткі правила
- Не вигадувати чисел. Кожне число в даних має колонку `source`. Нема джерела → поле порожнє + прапорець, а не «приблизно».
- Модель стратегій (simulate/optimize/rules, crops.yaml, rules.yaml) НЕ чіпати. Модуль ринку — окремий шар поверх готових результатів.
- Мережа: дозволено лише на кроці збору даних (OSRM, Вікіпедія/OSM для координат портів, пошук тарифу). Збірка сайту — без мережі, з кешу.
- Один етап = коміт + `pytest` зелений. `out/hls/tasks.json` не комітити.
- Тексти на сайті — людською українською, без сирих id (`sunflower_seed` → «насіння соняшнику»).
- Рішення записати в `docs/decisions.md` як D23 (і далі), формати — у `docs/contracts.md`.

## Етап 1. Експорт за країнами (обов'язковий)
Вхід: `data/raw/market/derzhstat_export_by_country.csv` (я вже витягнув з Держстату SDMX):
`product,uktzed,area,country_uk,year,value_kusd,volume_t,source`; роки 2021–2024 (2024 — останній річний); `area=_T` — усього.
Одиниці: вартість — тис. дол. США; обсяг — у тоннах (у джерелі код 1750 = кг за величиною, я переділив на 1000; перевір: пшениця 2024 ≈ 20,7 млн т).

Відповідність crop id → product:
- winter_wheat, spring_wheat → wheat (1001)
- barley → barley (1003)
- maize → maize (1005)
- soybean → soy (1201)
- winter_rapeseed → rapeseed (1205)
- sunflower → sunflower_seed (1206) + **окремо** sunflower_oil (1512) і sunflower_meal_cake (2306)
- pulses (0713) — лише якщо в crops.yaml є горох; інакше ігнор.

Скрипт `scripts/market_export.py` → `out/site/market_export.json`:
- для кожного product за 2024: топ-5 країн за вартістю, частка у `_T` (%), обсяг (тис. т), середня ціна = value_kusd×1000 / volume_t (дол./т; рахувати лише якщо volume_t > 0), тренд частки топ-1 2021→2024;
- для `_T`: загальний експорт (млн дол., млн т) по роках 2021–2024 (для спарклайна).

Головний інсайт, який треба показати (він чесний і з даних): **соняшник Україна експортує майже лише олією/шротом** (насіння 2024 ≈ 65 млн дол. проти олії ≈ 5,1 млрд). Тобто фермер продає соняшник переробнику в Україні, а не в порт. Текст картки для соняшнику — саме це.

Тести: суми часток ≤ 100; ціна не рахується при нульовому обсязі; кожен product з відповідності є в JSON.

## Етап 2. Найближчі порти і відстань (обов'язковий)
Порти: Одеса, Чорноморськ, Південний (Пiвденний), Ізмаїл, Рені. Координати брати з Вікіпедії/OSM, у `data/raw/market/ports.csv`: `port_id,name_uk,lat,lon,source_url`. Без URL — порт не додавати.

Відстань поле → кожен порт:
- `distance_straight_km` — haversine (є в market.py);
- `distance_road_km` — OSRM (`https://router.project-osrm.org/route/v1/driving/{lon},{lat};{lon},{lat}?overview=false`), лише для 5 пілотів + центрів 5 вікон (до ~50 запитів, пауза 1 с, кеш у `data/raw/market/osrm_cache.json` з датою запиту). Не вийшло → лише пряма з підписом «по прямій».
- Для 250 полів портфеля — лише пряма (OSRM не спамити).

Вихід: `out/site/market_ports.json` — для кожного поля: найближчий порт (за дорогою, якщо є, інакше по прямій), км, тип відстані.

## Етап 3. Порт проти елеватора (обов'язковий, малий)
З `data/raw/prices_candidates.csv`: для культури рахувати різницю CPT_port − EXW **лише в межах одного snapshot**. Зараз реально є лише кукурудза в EGB_2026-07 (перевір у note: EXW 9151, CPT 10675). Для інших — «немає ціни обох базисів з одного джерела».
Вихід — у той самий market_ports.json: `basis_spread_uah_t`, `snapshot`, `date`, `source`.
Текст: «На ту саму дату порт платив за кукурудзу на X грн/т більше, ніж елеватор (джерело, дата). Чи окупиться доставка — залежить від тарифу».

## Етап 4. Тариф і беззбитковість (бажано, лише з джерелом)
Шукай вартість автоперевезення зерна, грн/т·км, або грн/т на відстань — з датою не старше 2026 р. і URL (ринкові огляди, біржі перевезень, Укрзалізниця для залізниці).
- Знайшов → `data/market/transport.yaml` у форматі market.py (`{value, source}`), увімкнути market.py, показати: «доставка ≈ Y грн/т; порт вигідніший, якщо різниця > Y».
- Не знайшов за 40 хв → зупинись, в UI: «вартість доставки не враховано — немає перевіреного тарифу». Не підставляй «типові» цифри.
