# derzhstat_yield.csv — обласна врожайність Держстату (заповнює R2)

Колонки: `culture` (crop_id з model/crops.yaml), `oblast` (як у Держстаті, напр. «Одеська»), `year`, `yield_t_ha`, `source` (таблиця/URL/аркуш).

- Yx для пари культура × область = P90 цього ряду (leave-one-year-out під час валідації), ТЗ A3.
- Культура без рядків тут → Ya/Yx без т/га, позначка «немає даних для калібрування».
- Зараз: 48 рядків (пшениця озима, кукурудза, соняшник × Вінницька, Миколаївська, Одеська, Полтавська × 2015, 2020–2022), перенесено з baseline_model.py.
