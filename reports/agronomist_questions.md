# Питання до агронома (R2/R3)

Відкриті питання, які модель не може вирішити з першоджерел. Кожне — з посиланням на файл.

1. **Kc_ini ячменю озимого: 0,3 чи 0,4?** У FAO-56 Табл. 12 рядок «with frozen soils» (0,4) є лише для пшениці озимої; для ячменю — значення групи зернових 0,3. Зараз 0,3 (`model/crops.yaml`, winter_barley). Поки в ячменю немає Ky, на результат не впливає.
2. **Календарі сівби/фаз по зонах (степ / лісостеп / полісся)** для всіх культур — зараз заглушки (`BASELINE_V0`, `STUB_NO_SOURCE`) лише в степу й лісостепу; полісся (Волинь) — TODO, жодна культура там не готова.
3. **Ky для ячменю, вівса, жита, проса, нуту, ріпаку, льону, силосної кукурудзи, сидерату** — у FAO-33/FAO-56/FAO-66 немає. Потрібне інше першоджерело (вітчизняні досліди?).
4. **Довжини фаз FAO-56 Табл. 11** взято з рядків інших регіонів (Айдахо, Центральні США, Європа) — перевірити придатність для України або замінити.
5. **Пшениця озима, Ky:** обрано 1,00 (FAO-66 Табл. 2); 1,05 (FAO-56 Табл. 24 / FAO-66 Табл. 1) — у чутливості.
