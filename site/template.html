Календар

Меню сценаріїв

Фіксовані сівозміни, оцінені тією самою моделлю без пошуку (як поточна): маржа на полі за 4 роки 2027–2030, P10 / P50 / P90 за 25 роками погоди. Ротацію з 2–3 полів повторено по колу. Соняшник — з урахуванням насичення сівозміни (Полтавська ДСГДС). Культура без параметрів, т/га, ціни чи календаря — «немає даних», нічого не підставляємо.
Норматив · постанова КМУ №164 від 11.02.2010

Чи допускає норматив таку сівозміну

Лісостеповий регіон (Карлівка, Калинівка). Строки повернення культури на поле — жорстке правило: стратегію, що його порушує, застосунок не пропонує, а для фактичної — показує порушення. Частки культур норматив задає для господарства загалом, тож для одного поля це лише попередження.

Строки повернення

Частки культур у сівозміні

Межі часток для Лісостепу взято з правового дзеркала, де таблиця зламана: відповідність колонкам відновлено за порядком значень. Перед захистом звірити з zakon.rada.gov.ua.

«Не менше ніж через N років» читаємо буквально: між двома посівами культури мають пройти щонайменше N інших років. Кукурудзу норматив дозволяє 2–3 роки поспіль. Для пшениці ярої та чорного пару окремого строку немає. Фактичну сівозміну пілотного поля перевіримо, коли HLS NDVI покаже культури, а не лише «озима/ярова».

Перевірка моделі

Прогноз проти факту

МетодПомилка, %Порядок років, ρ

Обласна врожайність Держстату, 4 області × 3 культури × 4 роки ( пар). Рік, що перевіряється, не входив у калібрування.

Модель: FAO-56 (випаровування) + водний баланс ґрунту + коефіцієнт Ky. Календар сівби, Ky і запас вологи поки орієнтовні; спеку і заморозки не враховано.

Альтернативи з досліду

Органічні сівозміни ННЦ «ІЗ НААН»

Стаціонарний дослід 2021–2025, чорнозем типовий, Лівобережний Лісостеп. Середнє за 5 років; значення з позначкою * пораховані командою з таблиць звіту.

Компроміс «гроші проти води»: комплексне удобрення дає +33–54% урожаю, але забирає більше вологи з ґрунту; гречка найприбутковіша і найбільш водомістка. Даних по окремих роках у звіті немає, тож діапазон «сухий / вологий рік» для цих сівозмін рахує наша модель.

Мартинюк І. В., Цимбал Я. С. та ін. Теоретичні основи формування і функціонування короткоротаційних сівозмін за ведення органічного землеробства в умовах Лісостепу України. Вінниця: ТВОРИ, 2025.
